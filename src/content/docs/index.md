# {{name}} docs

{{name}} is one support desk for everything you build: live chat and support
email for every Product, in one inbox. These pages are short on purpose.

- [Getting started](/docs/getting-started): create your Workspace and add a Product.
- [Install the chat widget](/docs/widget): one script tag, or a React component.
- [Support email](/docs/email): forward `support@yourproduct.com` into the inbox.
- [Working the inbox](/docs/agent-workflow): replies, notes, saved replies, away mode.
- [Self-hosting](/docs/self-hosting): `docker compose up`, environment, reverse proxy.

## Key terms

| Term | Meaning |
| ---- | ------- |
| Workspace | Your team's account. Holds every Product, agent and conversation. |
| Product | One thing you support (an app, a site). Has its own widget key, domains and email address. |
| Conversation | A chat or email thread with one customer. Open, Pending or Closed. |
| Agent | A team member who answers Conversations. Admins also manage settings. |

## For agents and scripts

Every page is also available as plain markdown by adding `.md` to its URL
(`/docs/getting-started.md`). `/docs/llms.txt` lists every page for LLM tools.
